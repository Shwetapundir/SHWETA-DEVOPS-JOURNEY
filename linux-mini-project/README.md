# Linux Automation Mini Project

## Overview
This project demonstrates basic Linux automation used in DevOps environments.

## Features
- Shell script for system health monitoring
- Secure permissions using chmod
- Automated execution using cron jobs
- Output logging for monitoring and debugging

## Tools Used
- Bash
- Cron
- Linux permissions
- WSL (Ubuntu)

## Notes
- Absolute paths are used to avoid cron failures
- Cron behavior on WSL may differ from production servers
- Follows principle of least privilege

## Usage
Scripts are located in the `scripts/` directory and logs are stored in `logs/`.
