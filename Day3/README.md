# Day 3 - Linux Users, Groups & sudo

## What I learned
- What is a Linux user
- Root vs normal user
- What is sudo and why it is used
- What is a home directory
- Why each user has a separate home directory
- What are groups and why they exist

## Practical work
- Checked current user using `whoami`
- Used `sudo` to run admin commands safely
- Created users using `useradd`
- Understood home directory creation with `-m`
- Created groups using `groupadd`
- Added user to group using `usermod -aG`
- Created a shared DevOps folder with group permissions

## DevOps understanding
- Root can access all home directories
- Normal users are isolated for security
- Groups are used to manage team access
- `sudo` follows least privilege principle

## Commands practiced
- whoami
- groups
- sudo
- useradd
- groupadd
- usermod
- chown
- chmod
