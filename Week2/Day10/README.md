## Objective
Learn the basics of shell scripting required for DevOps automation.  
The focus is on automating common system tasks rather than complex programming.

---

## What is a Shell Script?
A shell script is a file containing Linux commands written in sequence so they can be executed automatically.

Shell scripts help DevOps engineers:
- Avoid repetitive manual work
- Automate system checks
- Run tasks consistently across servers
- Integrate automation into CI/CD pipelines
